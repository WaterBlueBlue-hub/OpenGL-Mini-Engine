# References

This project references public graphics and engine architecture material. The
course material, images, models, and other third-party media are not included
in the repository.

## Learning Material

- Zhao Xinzheng's OpenGL course, used as the original course reference.
- [LearnOpenGL](https://learnopengl.com/), used for general concepts such as
  model loading, materials, lighting, framebuffers, and instancing.
- [Unity Manual: GameObjects](https://docs.unity3d.com/Manual/GameObjects.html)
- [Unity Manual: Components](https://docs.unity3d.com/Manual/Components.html)
- [Unity Manual: Scene](https://docs.unity3d.com/Manual/CreatingScenes.html)

## Libraries

- [GLFW](https://www.glfw.org/)
- [GLAD](https://glad.dav1d.de/)
- [GLM](https://github.com/g-truc/glm)
- [Dear ImGui](https://github.com/ocornut/imgui)
- [stb](https://github.com/nothings/stb)
